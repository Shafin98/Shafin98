## 🚀 Featured Projects

🔹 **YUM Studio ERP** *(in progress)*
A custom, modular-monolith ERP being built module by module — starting with Attendance/Activity Tracking (QR-based session tracking, server-side timing, overtime and exception handling) and an HR module, all on a Django/DRF + PostgreSQL backend.

🔹 **YUM Studio CMS**
A Django CMS built with server-side rendering (Django templates), covering backend routing, middleware, and an admin dashboard — including slug-based routing, auto-logout middleware, dashboard health checks, and a migration from a free-tier database to Neon PostgreSQL.

🔹 **Ten Piece** *(production)*
Backend development for Ten Piece, focused on payment integration using the **Revolut Merchant API** — fully functional and live in production — along with mail integration for invoices/receipts and user messaging.
